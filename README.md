### What is this?

When an unexpected exception occurs in production or staging, reproducing it locally usually involves annoying boilerplate:
1. Creating a new test file.
2. Looking through the stacktrace to find which function threw.
3. Writing the correct relative import statements.
4. Setting up `describe`, `it`, and `expect().toThrow()` boilerplate.

`repro-gen` takes any stacktrace string or error log and instantly scaffolds a ready-to-run test file matching your test runner (**Vitest**, **Jest**, **Node Native Test**, or **Pytest**).

### Quickstart

Run directly via `npx`:

```bash
# Pass error string as an argument
npx repro-gen "TypeError: Cannot read properties of undefined at getUser (src/user.ts:42:15)"

# Pipe from crash log file or terminal output
cat crash.log | npx repro-gen

# Target custom output path
npx repro-gen "TypeError in src/auth.ts:25" --out tests/repro.test.ts
```

Or install it globally:

```bash
npm install -g repro-gen
```

### Supported Frameworks

* **Vitest** (Default for modern TypeScript/JavaScript)
* **Jest**
* **Node.js Native Runner** (`node:test`)
* **Pytest** (Automatic for Python tracebacks)
* **Mocha**

`repro-gen` automatically detects which test framework your repository uses by reading `package.json`, or you can force a framework with `--framework pytest`.

### GitHub Actions CI

To automatically scaffold a repro test when a CI integration step fails, add this to your workflow:

```yaml
- name: Scaffold Failing Test on Crash
  if: failure()
  uses: MinoForge-Official/repro-gen@main
  with:
    error: 'error.log'
    out: 'repro.test.ts'
```

### CLI Options

```text
Usage: repro-gen "<error or stacktrace>" [options]
       cat error.log | repro-gen [options]

Arguments:
  <error>               The raw error message, stacktrace, or path to crash log

Options:
  -o, --out <path>      Custom path for the generated test file (default: repro.test.ts)
  -f, --framework <fw>  Target test framework (vitest, jest, node:test, mocha, pytest)
  --dry-run             Print the generated test code without writing to disk
  -h, --help            Show help documentation
  -v, --version         Show version
```

### Programmatic API

```typescript
import { parseErrorStack, scaffoldReproTest } from 'repro-gen';

const parsed = parseErrorStack("TypeError: null at getUser (src/user.ts:42)");
const result = scaffoldReproTest(parsed, { framework: 'vitest' });

console.log(result.code);
```
